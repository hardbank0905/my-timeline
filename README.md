# マイタイムライン 公開版（PWA）

試作アーティファクトと同じ中身を、自分のスマホやPCで普段使いできる形にしたものです。
このフォルダをそのまま静的サイトとして公開すれば動きます。サーバー側のプログラムやデータベースは要りません。

## 中身

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体。試作と同じコードに、本物の埋め込みを使う設定（`window.MYTL_HOSTED = true`）を足したもの |
| `manifest.webmanifest` | ホーム画面に追加するための情報と、Android の共有メニューから受け取る設定（`share_target`） |
| `sw.js` | オフラインでもアプリを開けるようにするキャッシュ |
| `icons/` | アプリのアイコン |

## アーティファクト版との違い

- YouTube と Shorts は本物のプレイヤーで再生します。画面の真ん中に来たら再生し、外れたら一時停止します。冒頭の長さ（初期値は2分）で止まります
- X のツイートは X の公式埋め込みで表示します
- 画像や動画の直リンク（.jpg や .mp4 など）はそのまま表示・再生します
- TikTok は公式プレイヤーで表示します。自動再生は効かないので、タップして再生します

## データの保存先

ツイート・タイムライン・手元から追加した画像や動画は、**その端末のブラウザの中だけ**に保存されます。
公開したURLをほかの人が開いても、あなたのデータは見えません。そのかわり、スマホとPCでデータは共有されません。

## Macで今すぐ試す（0円・公開しない）

本物のYouTubeやXの再生だけ先に試したいときの方法です。スマホの共有メニューは、この方法では使えません（下の「公開のしかた」が必要）。

**方法1: VS Codeの拡張機能「Live Server」**（拡張機能＝VS Codeに足せる追加機能）
1. VS Codeでこの `pwa` フォルダを開く
2. 拡張機能で「Live Server」を入れる
3. `index.html` を右クリック →「Open with Live Server」。ブラウザが開きます

**方法2: ターミナル**
```
cd （pwaフォルダの場所）
python3 -m http.server 8000
```
ブラウザで `http://localhost:8000` を開きます。止めるときはターミナルで Ctrl + C。

`index.html` をダブルクリックで開く（`file://` で開く）と、YouTubeが再生できないことがあります。上のどちらかの方法で開いてください。

## 公開のしかた（どれか1つ）

### A. GitHub Pages（おすすめ）
1. GitHub に新しいリポジトリを作る（無料プランでは Pages を使うにはリポジトリを公開にする必要があります。公開されるのはアプリのコードだけで、データは含まれません）
2. このフォルダの中身をリポジトリの一番上に置く
3. リポジトリの Settings → Pages → Branch を `main` / `/ (root)` にして Save
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けるようになります

### B. Cloudflare Pages / Netlify
アカウントを作って、このフォルダをドラッグ＆ドロップでアップロードするだけで公開できます。リポジトリを非公開のままにしたいときはこちら。

## 共有メニューから送る

公開したURLを以下では `https://あなたのサイト/` と書きます。
アプリは `?url=…&text=…&title=…&tl=タイムライン名` 付きで開かれると、送り先を選ぶシートを出します。`tl` を省くと、前回選んだタイムラインが選ばれた状態になります。

### Android（Chrome）
1. Chrome で公開URLを開き、メニュー →「ホーム画面に追加」（または「アプリをインストール」）
2. 以後、YouTube や X の共有ボタンを押すと、共有先に「タイムライン」が出ます
3. 選ぶとアプリが開くので、送り先のタイムラインを選んで「ツイート」

### iPhone（ショートカット アプリ）
iPhone の Safari は、ホーム画面のWebアプリを共有先に出す仕組みに対応していません。かわりに標準の「ショートカット」アプリで共有メニューに足します。

1. ショートカット アプリ → 右上の「＋」
2. 名前を「タイムラインに送る」にして、詳細設定で **「共有シートに表示」をオン**。受け取る種類は「URL」と「テキスト」
3. アクションを順に追加する
   1. 「リストから選択」: 項目にタイムライン名（例: おすすめ / ゲーム / 音楽 / あとで見る）を入れる
   2. 「テキスト」: `https://あなたのサイト/?tl=［選択された項目］&url=［ショートカットの入力］`
      （［ ］の部分は変数を差し込む。入力は「URLエンコード」アクションを挟むと確実）
   3. 「URLを開く」: 直前のテキスト
4. YouTube や X の共有ボタン →「タイムラインに送る」→ タイムラインを選ぶと、アプリが開いて送り先シートが出ます

注意: iPhone では「Safari で開いたサイト」と「ホーム画面に追加したアプリ」でデータの保存場所が別になります。ショートカットは Safari で開くので、**iPhone では Safari のブックマークから使う**とデータが1か所にまとまります。

### PC（ブックマークレット）
ブックマークを新しく作り、URL欄に次の1行を入れます（`https://あなたのサイト/` は書き換え）。見ているページでこのブックマークを押すと、そのページをアプリに送れます。

```
javascript:(()=>{window.open('https://あなたのサイト/?url='+encodeURIComponent(location.href)+'&title='+encodeURIComponent(document.title))})()
```

### どこでも使える方法
URL をコピーして、アプリの画面（入力欄の外）で貼り付けると、同じ送り先シートが開きます。

## 音声について
ブラウザの決まりで、音の出る自動再生は「そのページで1回タップしたあと」だけ許可されます。音が出ないときは、動画の右下のスピーカーボタンを1回押してください。iPhone では制限が強めで、ミュートのまま始まることがあります。
