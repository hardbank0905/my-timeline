      シークレット

      隠したタイムラインは、タブ・検索・今日の1本・ゴミ箱のどこにも出ないよ。ブラウザの中に保存しているから、詳しい人が調べれば見える「目隠し」だよ。書き出したデータには入るから気をつけてね

      見られなくなった投稿をさがす

      YouTube・X・TikTokなどの投稿と、画像・動画のリンクを1つずつ確かめて、消えたり非公開になったりしたものに印を付けるよ。押したときだけ動くの。YouTubeなどは外のサービス（noembed.com）にURLを送って確かめるから、公開版だけで使えるよ

      貼れるURL

      YouTubewatch / youtu.be / Shorts → 埋め込み Xx.com / twitter.com の投稿 → 埋め込み 画像・動画.jpg .png .mp4 など直リンク → メディア その他記事・ブログなど → リンクカード

      URLをコピーして、入力欄の外で貼り付けると「タイムラインに送る」シートが開くよ。

      この試作のプレビュー環境では外部の埋め込みや画像を読み込めないため、埋め込みは同じ大きさの代わりの表示にしています。本番ではここに本物のプレイヤーが入ります。

      📖 データの守り方（書き出し・読み込みのやり方）

      データが消えちゃう場面

      • ブラウザの「履歴とWebサイトデータを消去」をしたとき → 消す前に書き出しておいてね
      • iPhone・iPadで、Safariのまま7日くらい開かなかったとき（Safariが自動で片付けちゃうの） → 共有ボタン →「ホーム画面に追加」して、そこから開くと消えにくいよ
      • アプリのURLが変わったとき（データはURLごとに別の箱なの） → 引っ越す前に書き出して、新しいURLで読み込んでね
      • スマホやPCが壊れた・なくしたとき → 端末の外（iCloud Drive、Googleドライブなど）にファイルを置いておけば大丈夫

      おすすめ: 週に1回くらい「ファイルで保存」。保存してから時間がたつと、上にお知らせが出るよ

      書き出すやり方

      1. ファイルで保存（いちばんおすすめ）: 下の「書き出す範囲」で「全部」を選ぶ →「ファイルで保存」→ iPhoneは「ファイル」アプリに保存、PCはダウンロードフォルダに入るよ
      2. 文字でコピー: 「書き出す」→「コピー」→ メモアプリやLINEのKeepに貼っておく
      3. QRコード: 「QRコードで渡す」→ 別の端末のカメラで読む（データが少ないときだけ使えるよ）

      読み込むやり方

      1. ファイルなら「ファイルから読み込む」でファイルを選ぶ。文字なら「読み込む」に貼って「この内容で置き換える」
      2. 「全部」で書き出したデータは、いまのデータと入れ替わるよ。1つのタイムラインだけのデータは、新しいタイムラインとして追加されるの
      3. パスワード付きのファイルは、読み込むときにパスワードを聞かれるよ

      ※手元から追加した画像・動画は、書き出しには入らないよ。元の写真は端末に残しておいてね

      🔐 パスワード付きの使い方の例
      1. 友達にLINEで渡す: 範囲で渡すタイムラインを選ぶ → パスワードをオン → 保存 → ファイルをLINEで送る → パスワードは会ったときに口で伝える（同じトークに書かないのがコツ）
      2. iCloudやGoogleドライブにバックアップ: 範囲は「全部」 → パスワードをオン → 保存 → 「ファイル」アプリでiCloud Driveに移す。もしアカウントをのぞかれても中身は読めないよ
      3. 機種変更: 古いスマホで保存 → AirDropなどで新しいスマホへ → 新しいスマホで「ファイルから読み込む」→ パスワードを入れる

      本物の暗号化（AES-256）だから、パスワードを忘れると自分でも開けないよ。メモアプリなど別の場所に控えておいてね

      1つのタイムラインだけ書き出したファイルは、友達の端末で読み込むと新しいタイムラインとして追加されるよ（いまのデータは消えないよ）
